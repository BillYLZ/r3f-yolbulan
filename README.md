# r3f-yolbulan

React Three Fiber ile 3B yol bulma (A*) görselleştirmesi.

## Çalıştırma

```bash
npm install
npm run dev
```

## Kullanım

- **Duvar / Başlangıç / Hedef**: Sol tıkla kareye uygulanacak modu seç. Duvar modunda sürükleyerek çizebilirsin.
- **Yolu Bul (A\*)**: Aramayı adım adım canlandırır; taranan kareler mavi, bulunan yol sarı.
- **Rastgele**: Her zaman çözülebilir rastgele bir harita üretir.
- Sağ tık sürükle: kamerayı döndür · Tekerlek: yakınlaştır

## Test

npm test
